# Анализ продаж Amazon: ETL, витрины данных и дашборды

## Обзор проекта

Проект представляет собой комплексный анализ данных о продажах Amazon (128 975 записей). Реализован полный цикл: от загрузки данных в ClickHouse до автоматизации ETL через Apache Airflow и создания дашбордов в Apache Superset и Metabase. Весь код и конфигурации хранятся в Git, ведётся история изменений.

## Бизнес-контекст

Онлайн-ритейлеру необходим автоматизированный процесс обновления ключевых метрик и наглядные инструменты для их мониторинга.

**Основные задачи:**
- Отслеживать динамику выручки и количества заказов
- Анализировать эффективность продаж по категориям и штатам
- Сравнивать сегменты B2B и B2C
- Автоматизировать ежедневное обновление данных

## Цели проекта

- Загрузить и подготовить данные в ClickHouse (128 975 строк)
- Настроить ежедневное автоматическое обновление агрегированных метрик через Apache Airflow
- Построить интерактивные дашборды в Apache Superset (управленческий и продуктовый)
- Построить дашборд в Metabase (география и тренды)
- Контейнеризировать всё окружение с помощью Docker
- Вести версионность проекта через Git

## Аналитический подход

- Преобразование типов данных (работа с датами, текстовыми полями)
- Агрегация и группировка по категориям, датам, штатам
- Расчёт ключевых метрик: выручка, количество заказов, средний чек
- Сегментация B2B / B2C
- Автоматизация ETL через Airflow (BashOperator + HTTP-запросы к ClickHouse)

## Ключевые инсайты

- **Выручка сильно зависит от нескольких штатов (Maharashtra, Karnataka, Tamil Nadu).**  
  На топ-3 штата приходится **~60%** общего объёма выручки (Maharashtra - **27.8%**, Karnataka - **17.2%**, Tamil Nadu - **14.9%**).  
  Это говорит о высокой географической концентрации и рисках.

- **Средний чек стабилен во времени, но заметны пики перед праздниками.**  
  Средний чек колеблется в диапазоне **2 800 - 3 200**, с пиками до **+18%** в предпраздничные недели.  
  Это позволяет планировать маркетинговые кампании.

- **B2B-сегмент мал, но имеет высокий средний чек.**  
  B2B составляет всего **2.3%** от количества заказов, но средний чек B2B (**~12 400**) в **4.2 раза** выше, чем B2C (**~2 950**).  
  Потенциал для развития корпоративных продаж.

- **Категории Shirt и Trousers - основные драйверы выручки.**  
  На них приходится **~41%** общей выручки (Shirt - **23.6%**, Trousers - **17.4%**).  
  Это ключевые категории для фокуса ассортиментных и рекламных усилий.

- **Airflow сокращает время подготовки отчётов**  
  Витрина `sales_daily` обновляется автоматически ежедневно в 9:00 без участия аналитика.

## Бизнес-ценность

- **Прозрачность:** единые метрики для всех дашбордов
- **Скорость:** ежедневное автоматическое обновление без участия аналитика
- **Гибкость:** возможность добавлять новые витрины и источники данных
- **Интерактивность:** фильтры по дате, категории, типу продаж

## Стейкхолдеры

- Руководство (общая динамика)
- Маркетинг (эффективность категорий и штатов)
- Финансовый отдел (тренды выручки и среднего чека)
- BI-команда (автоматизация и поддержка)
