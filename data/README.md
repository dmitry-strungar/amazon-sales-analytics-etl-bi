# Исходные данные

## Файл `amazon_sales.csv`

Данный файл содержит 128 975 записей о продажах Amazon.

**Структура данных:**

| Колонка | Описание |
|---------|----------|
| `index` | Порядковый номер записи |
| `Order ID` | Уникальный идентификатор заказа |
| `Status` | Статус заказа (Shipped, Cancelled и т.д.) |
| `Fulfilment` | Способ выполнения (Amazon, Merchant) |
| `Sales Channel` | Канал продаж |
| `ship-service-level` | Уровень сервиса доставки |
| `Style` | Стиль / модель товара |
| `SKU` | Артикул товара |
| `Category` | Категория товара |
| `Size` | Размер |
| `ASIN` | Стандартный идентификационный номер Amazon |
| `Courier Status` | Статус курьерской доставки |
| `Qty` | Количество единиц товара |
| `Amount` | Сумма заказа |
| `ship-city` | Город доставки |
| `ship-state` | Штат доставки |
| `ship-postal-code` | Почтовый индекс |
| `ship-country` | Страна доставки |
| `B2B` | Оптовый заказ (true / false) |
| `promotion-ids` | Идентификаторы промо-акций |
| `proper_date` | Дата продажи (тип Date, преобразована из текстового поля) |

## Почему файл не добавлен в репозиторий

Файл `amazon_sales.csv` весит более 10 МБ и превышает лимит GitHub для обычных файлов.
