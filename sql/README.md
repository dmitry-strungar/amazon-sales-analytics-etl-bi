# SQL-запросы для ClickHouse

В этой папке собраны 6 аналитических SQL-запросов, выполненных в ClickHouse на основе данных о продажах Amazon (128 975 записей).

Запросы демонстрируют владение:
- оконными функциями (`ROW_NUMBER`, `SUM OVER`, `PARTITION BY`)
- обобщёнными табличными выражениями (CTE)
- когортным анализом (через `JOIN` и `GROUP BY`)
- ABC-анализом (правило Парето 80/20)
- преобразованием типов данных
- агрегациями и фильтрацией

## Список запросов

| Файл | Описание |
|------|----------|
| `1_revenue_by_category.sql` | Общая выручка и количество заказов по категориям |
| `2_dynamic_by_month.sql` | Динамика выручки по месяцам (линейный тренд) |
| `3_abc_analysis.sql` | ABC-анализ товаров: доля выручки, накопленный процент, категории A/B/C |
| `4_dynamic_orders_revenue.sql` | Динамика количества заказов и выручки по месяцам |
| `5_top5_sku_per_category.sql` | Топ-5 товаров (SKU) по выручке внутри каждой категории |
| `6_b2b_b2c_analysis.sql` | Сравнение B2B и B2C: выручка, количество заказов, средний чек |
