# DAG-файлы Airflow

В этой папке хранятся DAG-файлы для автоматизации ETL-процессов.

## `update_sales_daily.py`

DAG для ежедневного обновления витрины `sales_daily`.

**Что делает:**
- Запускается каждый день в 9:00
- Собирает данные из таблицы `amazon_sales` за последние 7 дней
- Группирует по дате и категории
- Считает выручку и количество уникальных заказов
- Вставляет результат в витрину `sales_daily`

**Технические детали:**
- Использует `BashOperator` + `curl` для отправки HTTP-запроса в ClickHouse
- В реальной среде хосты и пароли заменены на заглушки
